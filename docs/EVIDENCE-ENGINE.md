# Evidence Engine

Raw is immutable. Deterministic ingestion registers sources and creates
evidence records. Reviewed mappings link evidence many-to-many to constructs,
audience models/personas, journey stages and process points. Mapping is
interpretation. Large structured datasets should be aggregated/calculated in
code; agent interpretation happens after reproducible calculation.

## Independent evidence dimensions

`provenance_type` describes how a record relates to research material:

- `source`: supplied source material; eligible as direct persona grounding.
- `derived`: a reproducible transformation of source/derived evidence;
  eligible only when `source_lineage`, `derivation_method`, and `scope` are
  recorded, lineage resolves to source evidence, and the persona claim stays
  within the derived record's scope.
- `analytical`: an interpretation or analysis; not eligible as primary
  grounding. It must include `source_lineage` pointing to source/derived
  records.
- `simulation`: generated by persona/research simulation; never eligible as
  persona grounding.

`fixture` independently records whether data is part of a fabricated test
environment. It never changes grounding eligibility. Source evidence in a
fictional acceptance fixture remains source evidence for that test; OS
simulation output remains ineligible even when a client is not a fixture.

The client-level `client.json` declares `fixture` and `real_client_data`.
Ingestion copies `fixture` from that file; it never infers it from source
content. New evidence records require both `provenance_type` and `fixture`.
Legacy records with `synthetic: false` are read as source evidence and
`synthetic: true` as simulation evidence for compatibility; migrate persisted
records before validating them against the current schema.
